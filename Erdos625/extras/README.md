# Extras

This directory is reserved for supplementary Lean files that are related to the formalization
but are not part of the main proof of `erdos_625`.

Currently empty. A candidate for future inclusion is `SharpProfileBound.lean`, which contains
a Cauchy-Schwarz approach to discharging
`paperPartBThresholdAverageClassAsymptoticLowerCriterionTarget_source` (Axiom 1 from HP-2023).
It was developed during the formalization but not used in the final proof. It is a
proof-engineering artifact showing how Axiom 1 might be discharged in future work.
