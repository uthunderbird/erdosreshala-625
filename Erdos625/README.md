# Lean Source Guide

This directory contains the Lean 4 source for the formalization of Erdős Problem 625
(chromatic number of G(n,1/2): proving that χ(G(n,1/2)) lies within a bounded gap of
the first-moment threshold, for all sufficiently large n). See [`../proof/proof.md`](../proof/proof.md)
for the mathematical proof, and [`../README.md`](../README.md) for the high-level
overview.

> **Provenance.** This Lean source, the companion writeups, and the
> five internal red-team audit passes (records kept in the Erdosreshala development repository, not included in this publish bundle) were
> generated by an LLM-agent pipeline (Anthropic Claude Opus 4.7,
> model id `claude-opus-4-7[1m]`, the 1M-context variant, plus the
> `operator` agent orchestrator at
> [https://github.com/uthunderbird/vibechord](https://github.com/uthunderbird/vibechord)
> whose codex-brain adapter ran `gpt-5.3-codex-spark` at `effort=low`)
> under human supervision. The 1M-context variant was load-bearing:
> `PartBProfileBridge.lean` is 29597 lines (~1.63 MB). The Lean kernel
> verifies the proof modulo the seven axioms below; the
> axiom-to-paper correspondence and the hybrid-axiom disclosures are
> documentary and were produced by the same pipeline. See
> [`../paper/main.tex`](../paper/main.tex) Acknowledgments and
> [`../DEVELOPMENT.md`](../DEVELOPMENT.md) ADR-7 for details.

## Analytical wrapper boundary

The root module imports `AnalyticalWrapper.lean`, which exposes two analytical theorems:

- `erdos_625_full_analytical_of_source_obligations`: original dependency-closure interface.
  Not Lean-certified: depends on three bridge-shaped WHP obligations not yet formalized
  in Lean (recorded in `../proof/ANALYTICAL_WRAPPER_AXIOM_SNAPSHOT.txt`).

- **`erdos625_low_discharged`** (added 2026-05-17): same top-level statement, all three
  bridge obligations replaced by paper-cited axioms. The Lean connection from paper axioms
  to the final theorem is fully proved (no bridge-shaped axioms in dependency chain).
  Axiom snapshot: `../proof/ANALYTICAL_WRAPPER_AXIOM_SNAPSHOT.txt`.

Current source-boundary caveats: the middle source artifact covers only
`x <= 1-epsilon_0` for fixed `epsilon_0 > 0`; the residual region
`x > 1-epsilon_0` is handled by the separate upper branch (Regime III).
The upper source artifact's explicit directed interval tables are now
supplied in `proof/source-notes/upper-boundary-r2-explicit-interval-tables-2026-05-13.md`.

## What `#print axioms` shows

```lean
import Erdos625.PublishableProof
#print axioms Problem625.Publishable.erdos_625_full_clean
```

returns exactly **7 entries**:

> **Axiom label glossary:** HYBRID = the axiom combines a published result with an in-repository, non-peer-reviewed numerical certificate; EXTRAPOLATION = the axiom extends a published result to a parameter regime not explicitly covered in the cited paper.
> These labels and the axiom-to-paper correspondences were produced by the same LLM pipeline that generated the proof (see provenance block above) and have not been independently verified by a domain expert.

- **4 paper-backed axioms**: two literal HP-2023 citations
  (`partB_alphaMinusTwo_firstMomentBelowOne_source`,
  `chi_alphaMinusTwo_lower_bound_whp`) and two axioms that are **not**
  literal one-citation paper quotes — `lemma_7_20_modified` (HYBRID:
  HP-2023 Lemma 7.20 + our in-repository, **not peer-reviewed**
  numerical certificate `lemma_7_10_ext`) and
  `zeta_alphaMinusTwo_upper_bound_whp` (EXTRAPOLATION:
  $\alpha-1\to\alpha-2$ symmetric version of Heckel 2024 Prop 5(b),
  **not literally in print**). See
  [`../paper/SOURCES.md`](../paper/SOURCES.md) (which also contains the dedicated axiom audit notes).
- **3 Lean kernel axioms**: `propext`, `Classical.choice`, `Quot.sound`.

**0 `sorryAx` on the proof path of `erdos_625_full_clean`.** The former unreachable `sorry` placeholders (proof terms that Lean accepts but marks unsound) in `PartBProfileBridge.lean`,
`ChromaticConnection.lean`, and `ZetaConcentration.lean` have been converted
to named `axiom` declarations (source seams) tracked by source-axiom snapshot files. An `axiom` declaration is an explicit, named assumption visible to `#print axioms`; unlike `sorry`, it does not produce a `sorryAx` in the axiom list, but it is still an unproved assumption. These converted axioms are not reachable from `erdos_625_full_clean` and are not counted in the seven axioms above.

`grep "^axiom" Erdos625/*.lean` will show additional `axiom` declarations
that are **not** reachable from `erdos_625_full_clean` (they belong to
alternative chains or legacy routes); see `../paper/SOURCES.md`.

### Analytical route

Terminology used in this section:
- **interval-skeleton consumer**: a Lean module that imports a numerical certificate (a finite table of interval bounds verified by an external tool) and exposes its conclusions as Lean hypotheses.
- **dependency-closure interface**: a single Lean theorem that aggregates all unformalized obligations for the analytical route so that the full dependency set is visible in one `#print axioms` call.
- **Regime I/II/III**: the three real-parameter ranges that partition the proof's case analysis (x ∈ [0, 0.029155], x ∈ [0.029155, 0.95], x ∈ [0.95, 1)).

| File | Contents |
|------|----------|
| `AnalyticalWrapper.lean` | Two analytical theorems: (1) `erdos_625_full_analytical_of_source_obligations` — original dependency-closure interface, still depends on three bridge-shaped WHP obligations; (2) **`erdos625_low_discharged`** (added 2026-05-17) — same statement with all three bridges replaced by paper-cited axioms (paperLowBranchChiLower_source, paperLowBranchZetaUpper_source, middleBranchCrossingComplementWHPAxiom, upperBranchPaperWHPAxiom). See `../proof/ANALYTICAL_WRAPPER_AXIOM_SNAPSHOT.txt`. |
| `LowBranch.lean` | Numerical certificate interface and interval-skeleton consumer for the low-branch (Regime I, x ∈ [0, 0.029155]) finite-room margins. Namespace: `Problem625.Analytical.LowBranch`. |
| `MiddleBranch.lean` | Numerical certificate interface and interval-skeleton consumer for the middle-branch (Regime II, x ∈ [0.029155, 0.95]) modified Lemma 7.20 package. Namespace: `Problem625.Analytical.MiddleBranch`. |
| `UpperR2.lean` | Numerical certificate interface, interval-skeleton consumer, and named appendix endpoint quantities for the upper-boundary (Regime III, x ∈ [0.95, 1)) r=2 branch. Namespace: `Problem625.Analytical.UpperR2`. |

## Architecture: how the four theorems compose

```
erdos_625              (uses 3 axioms on its proof path from PartBProfileBridge + ZetaConcentration; PartBProfileBridge.lean declares 7 axioms total)
  ↓ extend by replacing one axiom
erdos_625_97           (uses lemma_7_20_modified; 1 paper axiom)
  ↓ case-split on InMainRangeMod
erdos_625_full         (good-case via erdos_625_97; crossing-case via 3 α-2 axioms)
  ↓ clean rpow comparison via rpow_clean_bound_eventually
erdos_625_full_clean   (flagship; same 4 axioms total)
```

`#print axioms` for the flagship `erdos_625_full_clean` includes the
crossing-case axioms (which `erdos_625` does not need) and
`lemma_7_20_modified` (which `erdos_625_97` introduced), but does **not**
transitively include the three `erdos_625` axioms (`heckel_offdiag_term_bound`
and the `paperPartBExact*` axioms) because the flagship's good-case
branch goes through `erdos_625_97`, not `erdos_625`.
