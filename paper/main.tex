\begin{abstract}
This companion note records the publication-facing analytical proof route
for Erd\H{o}s Problem 625.  The claimed analytical theorem is that there is
a deterministic function $w(n)\to\infty$ such that
\[
  \Pr_{G\sim \Gnh}\bigl[\chrom(G)-\cochrom(G)\ge w(n)\bigr]\to 1.
\]
The current route takes $w(n)=\log\log n$ and splits according to the
fractional first-moment parameter $x=\alpha_0-\lfloor\alpha_0\rfloor$.
This paper is not a Lean certificate of that analytical route.  The Lean
files in the repository certify a separate fixed-$\varepsilon$
in-probability theorem, documented as a checked companion result.
\end{abstract}

\section{Statement}

\begin{theorem}[Analytical route theorem]\label{thm:analytical}
Let $G\sim\Gnh$.  There exists a deterministic function $w(n)\to\infty$
such that
\[
  \Pr\bigl[\chrom(G)-\cochrom(G)\ge w(n)\bigr]\to 1.
\]
In the route recorded here one may take $w(n)=\log\log n$.
\end{theorem}

The full proof writeup is \texttt{proof/proof.md}.  The shipped source
manifest is \texttt{proof/ANALYTICAL\_SOURCES.md}.  The upper-boundary
interval appendix is
\texttt{proof/upper-boundary-r2-explicit-interval-tables-2026-05-13.md}.

\section{Global parameter split}

Set
\[
\alpha_0=2\log_2 n-2\log_2\log_2 n+2\log_2(e/2)+1,
\qquad \alpha=\lfloor\alpha_0\rfloor,
\qquad x=\alpha_0-\alpha.
\]
Then $x\in[0,1)$.  The proof covers $x$ by three regimes:
\[
[0,0.029155],\qquad [0.029155,0.95],\qquad [0.95,1).
\]
The endpoint overlaps are intentional.

\section{Regime inputs}

\paragraph{Low branch.}
For $0\le x\le 0.029155$, the source theorem
\texttt{low-branch-quantitative-splice-theorem-2026-05-13.md} proves
\[
  \chrom(G)-\cochrom(G)\ge (c_*-o(1))\frac{n}{\log^3 n}
\]
with probability $1-o(1)$ for some fixed $c_*>0$.

\paragraph{Middle branch.}
For $0.029155\le x\le 0.95$, the source theorem
\texttt{good-branch-partial-away-from-one-theorem-2026-05-13.md}, with
fixed $\epsilon_0=0.05$, gives an asymptotically positive polynomial gap:
\[
  \chrom(G)-\cochrom(G)
  \ge n^{1-\varepsilon/2}-n^{1-0.9\varepsilon}-2n^{0.999}
  \to\infty.
\]
No parameter varies with $n$ in this invocation.

\paragraph{Upper boundary.}
For $0.95\le x<1$, the source theorem
\texttt{upper-boundary-r2-integrated-theorem-2026-05-13.md} gives
\[
  \chrom(G)-\cochrom(G)
  \ge 0.001\frac{n}{\log^3 n}-o\!\left(\frac{n}{\log^3 n}\right)
\]
with probability $1-o(1)$.  The finite interval evidence for the
$r=2$ certificate is shipped as the explicit appendix and the lightweight
checker \texttt{proof/verify\_upper\_boundary\_r2\_intervals.py}.

\section{Assembly}

For each sufficiently large $n$, the deterministic value $x(n)$ belongs
to at least one of the three ranges above.  Applying the corresponding
regime theorem gives a high-probability lower bound that dominates
$\log\log n$:
\[
  \frac{n}{\log^3 n}\gg\log\log n,
  \qquad
  n^{1-\varepsilon/2}-n^{1-0.9\varepsilon}-2n^{0.999}\gg\log\log n.
\]
Therefore
\[
  \Pr\bigl[\chrom(G)-\cochrom(G)\ge\log\log n\bigr]\to 1,
\]
which proves \Cref{thm:analytical}.

\section{Lean boundary}

The Lean development in this repository proves the theorem
\texttt{Problem625.Publishable.erdos\_625\_full\_clean}: for every fixed
$\varepsilon\in(0,0.001)$ and all sufficiently large $n$,
\[
  \Pr\bigl[\chrom(G)-\cochrom(G)\ge n^{1-2\varepsilon}\bigr]
  \ge 1-2\varepsilon.
\]
That is a checked in-probability companion theorem.  It is not a Lean
formalization of \Cref{thm:analytical}.  The analytical proof above is
currently a natural-language route assembled from shipped route notes and
explicit interval tables.

\section{Caveats}

The package should be described as a full analytical proof, not as a
Lean-certified proof of the analytical theorem.  The strongest remaining
non-formal boundary is independent mathematical review of the route notes
and the finite interval certificate.

For the Lean-facing certification plan, the current source-boundary caveats
are more precise.  The middle source artifact leaves the residual region $x>1-\epsilon_0$ open as a Lean-discharge target, and the upper source
artifact still depends on explicit directed interval tables replacing finite decimal certificate checks.
