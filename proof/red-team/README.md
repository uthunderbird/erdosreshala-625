# Red-Team Audit Trail — Index

> **Important shared-blind-spot caveat.** All artefacts indexed
> below were generated by the **same LLM-agent pipeline** that
> produced the proof being critiqued: worker model
> `claude-opus-4-7[1m]` (Claude Opus 4.7, 1M-context variant) driven
> by the `operator` agent orchestrator at
> [https://github.com/uthunderbird/vibechord](https://github.com/uthunderbird/vibechord)
> whose codex-brain adapter ran `gpt-5.3-codex-spark` at
> `effort=low`. These are **internal adversarial audits**, not
> third-party reviews. LLM-generated proofs may exhibit
> plausibility-driven failure modes that survive same-model
> critique because the proof author and the critic share
> training-data blind spots. See `../../README.md` Provenance and
> `../../DEVELOPMENT.md` ADR-10 / ADR-11 / ADR-12 for the full
> methodology disclosure. External verification by an unrelated
> reader, a different model, or a human mathematician is encouraged.

> **Filename convention note.** Audit notes in this directory follow
> the pattern `<target>-<date>.md`. The single exception is
> `lemma_7_10_ext.md`, which is a *source document* (the standalone
> description of the numerical certificate) rather than an audit note,
> and so does not carry a date suffix; the audit / disclosure pass on
> that certificate is the dated artefact
> `lemma-7-10-ext-disclosure-2026-05-11.md` directly below it.

## Mapping to the "five red-team passes" mentioned across the package

Several documents in the package describe the audit trail as
"five internal red-team passes". The mapping to the 19-artefact
inventory above is:

1. **Lean-theorem pass** (2026-05-11): `red-team-erdos-625-full-2026-05-11.md`.
2. **`proof/proof.md` pass** (2026-05-12): `red-team-proof-md-2026-05-12.md`.
3. **`paper/main.tex` round-1 pass** (2026-05-12): paper-side scratch critique, not shipped.
4. **`paper/main.tex` round-2 pass** (2026-05-12): paper-side scratch critique, not shipped.
5. **Strict lemma-by-lemma pass** (2026-05-12): `red-team-strict-lemma-by-lemma-2026-05-12.md`.

The remaining artefacts in this directory are: (i) the per-axiom
correspondence audit; (ii) the dedicated A1 / A4 disclosure notes
and the supporting numerical-certificate Python scripts; (iii) the `r2b-step1-*` plan + results pair for the $\alpha-2$ structural-margin scan; (iv) three publish-readiness packaging red-team rounds (rounds 1, 2, 3); (v) two legacy artefacts (superseded by the publish-readiness sweeps) preserved in `legacy/`. Together these **19** form the complete audit trail.
