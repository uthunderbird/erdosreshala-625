## 1. Objective

Numerically verify the following claim for **all** "bad" n (crossing n, μ_α(n) < n^{x₀+ε}, x₀ ≈ 0.02905) up to N ≥ 10⁶:

> **Claim R2B-S1.** For every bad n in [n_min, N],
> μ_{α−2}(n) ≥ n^{1.05}
> with substantial margin, where α = α(n) is the integer maximizing μ_α subject to μ_α ≤ 1, and
> μ_k(n) = C(n,k) · 2^{−C(k,2)}.

This is the analogue, for (α−2)-bounded colourings, of the standing condition that Heckel (2024)
requires for (α−1)-bounded colourings (`InMainRange`: μ_{α−1} ≥ n^{1.05}).

A positive numerical result is a **necessary** (not sufficient) condition for R2B to deliver
prize-exponent n^{1−ε} on the residual ~3% of n. A negative result kills R2B Phase 2.

---

## 2. Quantities to compute

For each n in the scan range:

| Symbol | Definition | Notes |
|---|---|---|
| `α(n)` | argmax over k of μ_k(n) subject to μ_k(n) ≤ 1 | the upper threshold; standard convention from HP-2023 §2 |
| `μ_α(n)` | C(n,α) · 2^{−C(α,2)} | log-domain computation (lgamma) — values range from ~10^{−ε log n} to 1 |
| `μ_{α−1}(n)` | C(n,α−1) · 2^{−C(α−1,2)} | should be ≥ n^{1.05} for "good" n |
| `μ_{α−2}(n)` | C(n,α−2) · 2^{−C(α−2,2)} | the quantity of interest |
| `x_α := log μ_α / log n` | dimensionless | "good" iff x_α ≥ x₀ + ε ≈ 0.02905 + ε (using rounded x₀; exact value 0.02905439) |
| `x_{α−2}` | log μ_{α−2} / log n | claim: ≥ 1.05 for **all** n; we want margin ≥ 0.5 |
| `bad(n)` | 1{ x_α < x₀ + ε }, ε = 10^{−3} | "bad" / "crossing" indicator |
| `margin(n)` | x_{α−2}(n) − 1.05 | the headline number; must stay > 0 with margin |

All exponentials/binomials in log domain via `math.lgamma` (Python) or `mpmath` if higher precision
needed near integer jumps of α.

---

## 3. Predicted theoretical value

From HP-2023 Lemma 6.2 / standard asymptotics:

   μ_{α−2}(n) / μ_α(n) = n^{2 + o(1)} / (log n)^{2 + o(1)}

So:

   x_{α−2}(n) = x_α(n) + 2 − 2 · log log n / log n + o(1/log n).

For bad n with x_α ∈ [0, x₀] ≈ [0, 0.02905] (exact x₀ = 0.02905439):

   x_{α−2}(n) ∈ [2 − 2 log log n / log n, 2.029 − 2 log log n / log n] + o(1).

For n = 10⁶:  log n ≈ 13.82, log log n ≈ 2.63, correction ≈ 0.380.
Predicted x_{α−2} ∈ [1.620, 1.649]. Margin over 1.05: **≥ 0.57**. Healthy.

For n = 10¹²: correction ≈ 0.232. Predicted x_{α−2} ≥ 1.77. Even healthier.

**Sanity:** the claim should pass with substantial margin. The risk is at very small n (low hundreds)
where lower-order terms could conspire; not a concern for the formalization target (asymptotic n).

Pass A is one script (~1 min run, single-core). Pass B–D append.

## 6. Check criteria (go/no-go)

| Criterion | Threshold | Action if violated |
|---|---|---|
| **C1** | min margin over bad n ≤ 10⁶ | ≥ 0.50 | **GO** for R2B Phase 2 mathematical work |
| **C2** | min margin over bad n ≤ 10⁶ | ∈ [0.10, 0.50) | proceed with caution; redo Pass D at higher precision; review R2B exponent budget |
| **C3** | min margin over bad n ≤ 10⁶ | < 0.10 | **NO-GO** for R2B Step 2 as stated; revisit exponent target (1.05 → smaller?) or pivot to N2/N4 |
| **C4** | asymptotic slope of x_{α−2} − x_α | ∈ [2 − 0.4, 2 + 0.05] for n ≥ 10¹⁰ | confirms HP-2023 Lemma 6.2 ratio formula |
| **C5** | bad-density at N=10⁶ | ≈ 3.5% ± 0.5% | reproduces N5 feasibility scan (cross-check) |
| **C6** | reproducibility | mpmath recomputation of worst-margin n matches float64 to 3 sig figs | else flag numerical instability and rerun all of A in mpmath |

A **GO** verdict is necessary but not sufficient for R2B: it confirms the first-moment input
but says nothing about the (α−2)-bounded analogue of Heckel 2024 Prop 5(b) (second-moment, Part C)
or the (α−2)-bounded Part B / tameness arguments. Those remain mathematical work in R2B Steps 2–4.

## 7. Risks & mitigations

- **Risk:** lgamma cancellation near integer jumps of α. **Mitigation:** Pass D in mpmath.
- **Risk:** definition mismatch — α here is `argmax μ_k s.t. μ_k ≤ 1`; HP-2023 uses essentially
  the same but check signs at crossing. **Mitigation:** print α, μ_α, μ_{α−1}, μ_α-from-table
  for n ∈ {1000, 10000, 100000} and compare against the table in HP-2023 §2 / Heckel 2024 §2.
- **Risk:** "bad" boundary ε choice (10^{−3}) is arbitrary. **Mitigation:** also report results
  for ε ∈ {10^{−2}, 10^{−3}, 10^{−4}} and verify the worst-margin n is stable.
- **Risk:** the 1.05 exponent is the wrong target — R2B may need 1.0 + δ for some specific δ
  set by Phase 1 modification. **Mitigation:** report margin against both 1.05 (HP-2023 native)
  and 1.0 + δ for δ ∈ {0.01, 0.05, 0.10}.
